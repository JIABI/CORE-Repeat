# 闭式基线修复与同目标表示比较

2026-09-12；在本轮新结果产生前记录。仅使用现有 `data/source5_primary_fullcontrols` 的 639 个已开放 DEV 对象、四个既定角色。此工作是开发诊断，不是新的独立认证。旧 Claude 脚本及结果保留，新实现与运行输出另存。

## 问题与范围

1. 正确估计的闭式条件高斯模型能预测多少原测量结构和追加收益？
2. 原始输入、可靠性基、现有 JEPA 表示能被同一种预测头读出多少相同的未来测量信息？线性探针检验线性可读性，不声称证明所有非线性信息已经丢失。
3. 同预算选择的实际净值和风险怎样，是否在已有 DEV 划分间稳定？

生物 kernel 计划已单独记录到上级目录 `BIOLOGICAL_KERNEL_PLAN.md`。本轮不启用机制注释、不修改 JEPA 目标、不打开 FINAL、第五重复或新候选。

## A. 完整原空间闭式条件模型

训练内拟合均值／标准差的仿射尺度，与现有尺度口径一致。±8 仅作为训练矩估计的稳健化规则；所保存批次均值必须与实际拟合数据一致。部署条件化使用原始观测的仿射坐标，不能把非线性截断后的数值冒充原空间高斯的精确条件值。

训练 PCA K=200（小型工程样例按可用秩缩减，真实实验不缩减）。在子空间内估计共享信号协方差及孔内噪声协方差；信号投影为半正定，噪声采用固定 0.05 对角收缩并设数值下限。原空间其余残差采用正的逐坐标噪声模型；不能在生成时把 3,417 个方向设为确定性零。其统计近似与条件同方差假设明确报告，不称普适信息上限。

未来孔共用同一个后验生物／共享效应样本，各孔技术残差独立。预测和 NLL 均在完整 3,617 维原测量空间；原物理孔上的实际收益不截断、不投影、不换验证目标。

基线每对象使用 1,024 个联合 Monte Carlo 样本，分块计算；固定随机种子并报告收益均值的 Monte Carlo 标准误。不根据结果提高／降低样本数或挑种子。

固定分区：383 train 拟合，validation 96、calibration 64、evaluation 96 分开报告。它们均已被历史分析打开，不再称 untouched。

## B. 同一个目标的表示比较

输入为角色 X；目标固定为 Z1、Z2、V 三个未来孔的全部原测量坐标。主指标为同一训练尺度下的 MSE、同一训练均值基线的预测改善及标准 R²；保留逐对象 SSE 以便配对比较。不得比较各表示自身重建的 R² 来宣称信息优劣。

比较原始仿射 X、训练内可靠性基 K=200、已有两个 batch128 JEPA 臂的 epoch60 教师 profile encoder。两条既有学习率臂都报告，不从结果中挑一个。教师投影头不是实际导出的 profile encoder，二者不混称。新增目标函数和再训练 JEPA 不在本轮。

所有表示采用相同多输出 ridge 预测头，训练输入标准化与维数归一化，alpha 候选固定为 0.001、0.01、0.1、1、10；仅在训练对象内部三折选择。容量／输入维数差异和固定表示条件下的头部调参明确报告，不声称是信息论测量。目标标签不做 clipping；JEPA 沿用其预训练时的仿射输入。可靠性表示也不在推理时额外截断输入。

固定383对象上的表示拟合与旧 JEPA 预训练身份对齐。已有 JEPA 的预训练对象不得出现在它的外层测试折。

## C. 同预算策略价值与风险

动作 Z1、Z2、Z1Z2；成本每孔 0.01，正类门限 0.005，NULL 为收益≤0，原收益公式与风险定义保留。

对固定 5%、10%、25% 覆盖，分别报告选中均值、全候选归一化价值、总孔位、NULL/FDP、FPR、敏感度，并与同动作同孔位预算随机策略比较。另以相同物理孔位预算跨动作比较；固定动作参照只由训练数据的平均收益／孔选择，不能用评价结果选出“最佳固定”。全体追加和 STOP 单独列出预算，不把不同预算当公平比较。

排序使用期望收益，低 pNULL 排序为另一项预先声明的诊断，两者均报告；不搜索联合门限，不颁发新授权。概率 AUC 与相关使用标准并列名次处理；选择并列由稳定对象身份打破。

对象级配对 bootstrap 仅给定当前共享批次布局下的探索性不确定性，不声称批次总体覆盖保证，也不改变原合同。

## D. 已开放 DEV 稳定性

闭式模型做三次三折重复交叉验证，种子 20260912、20260913、20260914。每折重新拟合全部统计量；按可在决策时获得的 X 能量五分位分层，不按收益选样、不删除极端对象。报告各折及每次完整折外预测，重复结果不能拼成更多独立样本。

冻结 JEPA 表示的稳定性检查只在另外256个非预训练对象中做同样三次三折：383个预训练核心始终不进入测试，所有表示变换固定由这383个对象拟合，预测头用核心加当折开发训练部分拟合。此项衡量固定表示的头部外推稳定性，不等同于每折重新预训练 JEPA。

基于四孔重复的可靠性分层只可用于事后诊断展示，不作为决策输入，也不以重划分宣称得到新的独立验证。
